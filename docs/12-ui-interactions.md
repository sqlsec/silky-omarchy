# 12 · UI 交互优化总览

简体中文 | [English](en/12-ui-interactions.md)

这些天对 Omarchy + MacShell 桌面做的界面与交互优化，按“在哪里能感觉到”分组。每条只写效果，细节、原理和回滚方式看后面链接的文档。

整体原则：**看起来和用起来都像 macOS**（玻璃材质、单色图标、深浅色同步、macOS 的快捷键习惯），**不卡**（按需捕获、事件驱动、预热），**不打架**（同一个键、同一个功能只有一个入口）。

## 深色 / 浅色：全桌面一起切换

切换的信号是 `org.gnome.desktop.interface color-scheme`。MacShell 的「外观」（含“自动”，白天浅色、晚上深色）和 `omarchy theme set macos-tahoe-light/dark` 都会写它，下面这些会跟着一起变：

| 跟着变的部分 | 文档 |
| --- | --- |
| MacShell 菜单栏、Dock、Spotlight、控制中心 | [02](02-macshell.md) |
| GTK / libadwaita 应用（Finder 风格的 Nautilus）、光标、MacTahoe 图标 | [04](04-macos-theme.md) |
| Omarchy 自带菜单（Super+Esc、Super+Ctrl+M、剪贴板、表情） | [11](11-menu-glass.md) |
| WowType 候选框皮肤（含微信内的候选条） | [09](09-wowtype-glass.md) |
| Super+K 快捷键面板 | [10](10-shortcuts.md) |
| Obsidian 笔记（主题「跟随系统」） | [15](15-obsidian.md) |

控制中心「显示」页里新加了「外观」开关，可以直接在那里切换。

Dock 的玻璃底色原来写死为深色，切换后只有右键菜单和悬停标签跟着变；现在整块 Dock 玻璃（着色、边缘高光、启动预览条）也随深浅色一起切换，见 [02](02-macshell.md)。

## 菜单栏

- 顶栏随前台窗口切换，浏览器显示历史记录和书签，Nautilus 显示「前往」。[02 · 按应用切换顶栏菜单](02-macshell.md#按应用切换顶栏菜单)
- 全部简体中文；“关于本机”更紧凑（[02](02-macshell.md)），Edge 渠道显示为 `Edge · 提交`，后跟淡色的 `月-日 构建`，不再像降级（[02](02-macshell.md#关于本机里-edge-版本像降级)）
- 网速、CPU 温度、电池三个监控按钮，顶栏网速上传在上、下载在下，点开是玻璃面板：网速有应用流量排行和 IP（点击复制），温度有进程排行和硬件概览，电池有整机功耗曲线（仅电池供电时可测）和健康度，还能设置充电上限（[02 · 顶栏系统监控](02-macshell.md#顶栏系统监控)）
- 电池是 macOS 26 的窄胶囊，里面只有数字、没有 `%`，颜色区分充电（绿）、外接电源直供（取当前壁纸的强调色，换壁纸跟着变）、电池供电（中性色）、低电量（红，低于 20%）；左键看电池详情，右键切换电源模式（省电 / 平衡 / 高性能），右键面板里还有「显示电量百分比」开关（[02 · 电池图标](02-macshell.md#电池图标)）
- 托盘图标统一成单色线条：Chrome、ChatGPT、Clippy、Netcatty、Remmina、Clash Verge、微信；跟随深浅色变色（[02](02-macshell.md#顶栏系统监控)）
- 铃铛打开的通知面板里，通知按应用叠成一摞（点开展开，只显示最近 3 个应用），和下方的小组件在同一个滚动区里、边缘淡出；小组件有：天气、股市、屏幕使用时间、电池、日历、系统、AI 用量（Claude、Codex、DeepSeek），卡片和控制中心同样是液态玻璃，各有小 / 中 / 大三种尺寸，强调色跟随壁纸，天气卡也是半透明玻璃；右键小组件可切换尺寸、设置天气城市、增删并拖动排序全球股票代码（也可输入名称）、填写 DeepSeek API Key；点「编辑小组件」后点一下换尺寸、拖动排序、「−」删除，从下方添加新组件（[02 · 通知中心小组件](02-macshell.md#通知中心小组件)）
- 自动对比度改成事件驱动：只有窗口出现、关闭、移动时才重新测亮度，背后只有壁纸时直接读壁纸文件，不再截屏，打开控制中心的停顿从约 76 ms 降到约 19 ms（[02](02-macshell.md#打开菜单和控制中心时卡顿)）
- 浮动窗口不会被拖到菜单栏下面（[03](03-silky-gestures.md#浮动窗口不能拖到菜单栏下面)）

## 控制中心

- 控制中心默认采用 macOS 26/27 风格的独立悬浮液态玻璃气泡（全圆角胶囊、正圆开关、清透折射与 360° 镜面高光环），深浅外观跟随系统切换，仍可在设置中随时切回统一的毛玻璃大底板（[02 · 控制中心](02-macshell.md#控制中心)）
- 新增「显示」页：亮度滑条、夜览开关、深浅色外观开关，交互方式和「声音」页一致（[02 · 控制中心](02-macshell.md#控制中心)）
- 拖动音量滑条（控制中心、菜单栏音量弹窗、菜单栏滚轮）时会发出提示音，声音大小跟着滑条走；松手时再响一次，就是最终音量。系统设置里关掉「界面音效」即可静音
- 「声音」页的输入滑条下面有实时麦克风电平条：安静时只亮几格，说话时跳起来，红色表示快要削波；只在这一页打开且麦克风未静音时监听

## Dock 与应用程序面板

- 系统切换到 Folio 后，Dock 上旧的 Nautilus 固定项会在更新时迁移到 Folio。[02 · Dock 中文件打不开](02-macshell.md#dock-中文件打不开)

- MacShell 的 Dock 图标换成深紫玻璃底和银紫色 M 字标记（[02 · Dock](02-macshell.md#dock-图标与设置窗口)）
- 菜单栏、控制中心、通知中心、应用程序面板和 Dock 改用 Hyprland 模糊：拖动窗口时玻璃同帧跟随，深浅色外观都有接近 Liquid Glass 的浅色调和顶部光泽，菜单栏背后几乎完全透明；「关于本机」的「更多信息…」按钮变淡（[02](02-macshell.md#改用-hyprland-模糊普通模糊)）
- （可选）Dock、菜单栏所有弹出面板（左上角菜单、应用菜单、Wi-Fi、蓝牙、音量、电池/状态、控制中心独立气泡、通知中心与通知横幅）及其他 MacShell 浮层（Spotlight、应用面板、窗口切换器、壁纸选择、OSD）均由 Hyprland 插件同帧画成 macOS 26/27 光学液态玻璃（边缘凸透镜折射、细微色散与 360° 双对角镜面高光）；顶部菜单栏细条（`macbarbg`）保持原生模糊（[02](02-macshell.md#dock-液态玻璃插件原型)）
- 只保留 MacShell 的 Dock，Omarchy 自带的 Dock 永久关闭（[02](02-macshell.md#只保留-macshell-的-dock)）
- 图标的光学缩放以中心为基准，悬停放大时不再往一边偏（[02 · Dock](02-macshell.md#dock-图标与设置窗口)）
- 点过 Dock 图标后，名称标签要等指针再移动 4 px 才出现（和 macOS 一样），连续点击不再卡 60–70 ms（[02](02-macshell.md#应用程序面板交互)）
- 应用程序面板（Launchpad）：滚轮每格 320 px，触控板 / 触控屏松手后平滑减速；打开时整块面板从 114% 缩到 100%、由模糊变清晰；首次打开前预热，不再卡约 200 ms；连续点击“应用程序”图标时弹簧直接反向（[02](02-macshell.md#应用程序面板交互)）
- 在 Dock 右键点「文件」，可以直接打开主文件夹、桌面、文档、下载和图片。[02 · 文件右键菜单的常用目录](02-macshell.md#文件右键菜单的常用目录)
- Folio 点黄灯后以 GPU 驱动的收拢动画缩成 Dock 分隔线和废纸篓之间的窗口缩略图，窗口就地交接给动画后再连续收拢，全程保持原亮度。点缩略图恢复。Dock 线性腾出和收回缩略图的位置（[02](02-macshell.md#窗口最小化)）
- 「罗技鼠标」（Omalogi）出现在应用程序面板和 Spotlight，图标是和 MacTahoe 统一的亮蓝瓦片；运行时 Dock 显示它自己的图标（[14](14-omalogi.md#应用程序入口与图标)）

## 玻璃与流畅度

- Vulkan 实时玻璃；菜单和控制中心只在可见时、只对和玻璃相交的窗口做捕获，窗口静止后自动降频（[02](02-macshell.md#默认玻璃参数)）
- 切换窗口焦点（浮动窗口叠放顺序变化）时，玻璃背景会跟着刷新；窗口标题变化不会唤醒刷新（[02 · 玻璃](02-macshell.md#焦点切换时玻璃背景跟着刷新)）
- 弹出面板边缘的错位暗带修复（折射强度和斜面收窄）（[02](02-macshell.md#玻璃面板边缘错位)）
- 消除鼠标指针周期性卡顿；90 Hz 内屏（[02](02-macshell.md#鼠标指针周期性卡顿)）
- 浮动窗口使用预先模糊的桌面背景后，拖过叠放的窗口仍能跟上 90 Hz 内屏（[02](02-macshell.md#90-hz-下拖动窗口卡顿)）
- 崩溃后不会出现两个菜单栏 / 两个 Dock；重启后菜单栏、Dock 和滚轮方向不再丢失（[02](02-macshell.md)）
- 后台程序把 CPU 跑满时，窗口动画、菜单栏、Dock 和指针仍然顺滑：Hyprland、MacShell 和输入法优先调度，接电时 GPU 不会从最低频起步（[16](16-desktop-priority.md)）

## 窗口

- 计算器、Omacut、Write 和媒体查看器使用共用红黄绿按钮，半屏与四角布局按窗口尺寸启用。微信和 PuTTY 控制台的工作内容以完整不透明度显示。[系统应用按窗口标准整改](04-macos-theme.md#system-app-audit)
- Silk 自绘的浮动窗口标题栏带圆形红绿灯和半透明底色（[04](04-macos-theme.md#红绿灯标题栏)）
- MacShell 自己的窗口（设置、关于本机）保持原尺寸、居中，打开时没有白边闪烁（[02](02-macshell.md)）
- 新窗口直接显示，Firefox 等 GTK3 CSD 窗口打开首帧不再闪出虚化光晕和偏移，关于本机的磨砂随下方窗口实时变化。见 [窗口打开与实时磨砂](02-macshell.md#打开窗口时壁纸闪现与关于本机实时磨砂)。
- 设置窗口左侧导航列表：鼠标滚轮每格 140 px 平滑滚动，触控板保持原生惯性（[02 · 设置窗口](02-macshell.md#dock-图标与设置窗口)）
- `Super+T` 在同一工作区平铺分屏。用 `Super+Alt+T` 进入单窗口平铺，再按一次切回浮动并恢复挪走的窗口。([10 · Super+T](10-shortcuts.md#supert))
- 通过快捷键切回浮动时，窗口上沿会避开菜单栏。([10 · Super+T](10-shortcuts.md#supert))
- 微信里点开图片或视频，查看窗口总是浮动居中，并以 900×620 的适中尺寸打开，不再顶着菜单栏；聊天记录窗口同样收窄居中（高度不低于微信自身的 720 下限）。([10](10-shortcuts.md#微信图片查看器与聊天记录窗口的默认尺寸))
- 微信在后台收到消息或更新状态时，不再自动抢焦点浮到当前窗口上方。([10](10-shortcuts.md#微信后台不再自动抢焦点置顶))
- 罗技鼠标配置（Omalogi）是普通窗口：居中浮动 1280×700（不挡 Dock），可平铺 / 全屏、进 Alt+Tab，切工作区不再压在最上面；再次打开只聚焦已有窗口；有线和无线鼠标同时连着时可在窗口右上角切换（[14 · 独立窗口](14-omalogi.md#独立窗口)）
- Remmina 远程桌面显示简体中文，主窗口的实色连接列表和磨砂标题栏实时跟随日间 / 夜间。连接窗口的工具栏移到顶部，带红绿灯和连接名，按住标题栏空白处即可拖动窗口，换成细线图标和直白的提示，少用的操作收进 `⋯`，只有一个会话时隐藏标签栏。主窗口列表的选中行为强调色圆角胶囊。远程 Windows 画面在高分屏上 1:1 清晰显示，默认 150% 缩放，不再像 200% 那样又大又虚（[高分屏缩放](04-macos-theme.md#remmina-hidpi)）。见 [Remmina 简体中文与 macOS 外观](04-macos-theme.md#remmina)。
- 罗技鼠标配置的编辑区使用实色底，浮动时显示共用红黄绿按钮。见 [Omalogi 独立窗口](14-omalogi.md#独立窗口)。

## 手势（触控板 / 触控屏）

- 微信主窗口降低透光度，触屏拖动会话列表时使用连续滚动（[01](01-touchpad-gestures.md#微信会话列表触屏滚动)）

- 触控板：自然滚动（鼠标也是）、三指拖移、四指横滑切换工作区，过渡动画更顺（[01](01-touchpad-gestures.md)）
- 触控屏：三指滑动和边缘单指滑动切换工作区、到头回弹；触控拖动和双指缩放浮动窗口；拖动终端标题栏（[03](03-silky-gestures.md)）
- 四指 / 五指捏合识别、快速连续点击不丢（[03](03-silky-gestures.md)）
- 触控板 / 触控屏四指上滑：当前工作区所有窗口；四指下滑：当前应用所有窗口。线性跟手、松手后匀速走完，中途可再按住打断或反向；点击或轻点窗口切换过去（[13](13-window-overview.md)）
- 四指上滑总览顶部显示可点击的工作区预览，桌面壁纸不压暗。点击预览会让窗口左右滑动，触控板四指左右滑时窗口会跟随手指（[13](13-window-overview.md#工作区预览与切换)）

## 键盘与快捷键

- MacShell 和 Omarchy 冲突的键只留 MacShell（Super+Space 聚焦搜索、Super+V 剪贴板历史、Alt+Tab 切换应用、Alt+Shift+Tab 反向、Super+L 锁屏），Omarchy 的动作挪到空闲键（[10](10-shortcuts.md#改动后的键位)）
- Super+K：macOS 27 风格的可搜索快捷键面板，分组、⌘⌥⌃⇧ 键帽，回车直接执行（[10](10-shortcuts.md)）
- 截图（PrtSc）只截一次、不发通知，右下角浮动预览可拖出或标注（[02](02-macshell.md#截图不再发通知)）
- 截图选择界面可右键退出，遮挡选项在原工具栏内按需显示，选定后自动收起，三档模糊采用柔和的磨砂过渡（[02](02-macshell.md#截图遮挡档位与右键取消)）
- 截图贴图可以拖动、等比缩放和调透明度，常用操作收在随系统日夜切换的玻璃右键菜单（[02](02-macshell.md#独立截图贴图)）

## 菜单与弹出层

- Omarchy 自带菜单改成半透明模糊卡片：不压暗屏幕，选中行用强调色填满，Inter 字体，深浅色实时切换（[11](11-menu-glass.md)）
- WPS 划选文字弹出的迷你工具栏不再抢占初始焦点，连续划选多段文字时可直接重新框选，不再把上一段文字带过去（[09](09-wowtype-glass.md#wps-的候选栏迷你工具栏与字体)）

## 输入法

- WowType 候选框：圆角毛玻璃皮肤，Inter 12 号字，高亮贴边且和外框共用 8 px 圆角，半透明底色能透出模糊，选中第一个候选时两个圆角重合；修复微信里候选条重影；微信里拼音改在候选条第一行显示，连续打字时候选条不再闪烁（[09](09-wowtype-glass.md#微信里候选条连续打字时闪烁)）
- WowType 和 vinput 语音输入：vinput 实时草稿和随音量起伏的声波显示在同一个毛玻璃浮条里（[05](05-voice-overlay.md)）

## 锁屏与开机

- 快捷键、菜单、闲置、合盖全部用 MacLock 锁屏（[07](07-lock-and-boot.md)）
- 开机磁盘解锁界面做成 macOS FileVault 风格（[07](07-lock-and-boot.md#开机界面)）

## 文件管理器与终端

- Folio 使用 Finder 图标、蓝色文件夹和紧凑的红黄绿顶栏，重启和系统 Folio 更新后继续使用已安装的优化版。磨砂只出现在左侧导航栏，右侧文件区和路径栏为实色。绿灯与 `Super+F` 一样切换全屏，进入显示加号，退出显示斜角。右键或长按绿灯可选半屏和四角布局，全屏时黄灯置灰。拖窗口到左右边缘可预览并吸附到半屏或四分之一屏。分栏视图选中并展开子文件夹时，顶部路径栏、路径编辑和复制按钮同步显示到该子文件夹。鼠标单击或触屏轻点顶部路径可编辑，鼠标点击或触屏轻点文件区空白可取消，拖动路径区域可移动窗口，右侧复制按钮可复制完整路径。触屏单指滑动可滚动文件区。分栏视图单指轻点按左键处理，长按或双指轻点打开右键菜单。右键侧栏的「回收站」会显示居中的「清空」。见 [04 · Folio 的 Finder 外观](04-macos-theme.md#folio-的-finder-外观)。

- Folio 浮动窗口打开时首帧直接呈现，不再先闪出一整块空白虚化玻璃，在高对比背景上的侧栏圆角使用干净的磨砂边缘。见 [Folio 的 Finder 外观](04-macos-theme.md#folio-的-finder-外观)。
- Files 和 Foot 的红黄绿按钮圆面等大，悬停符号用相同的路径和线宽，退出全屏用内收斜角。见 [Foot 的 Tahoe 外观](04-macos-theme.md#foot-glass)。
- Foot 使用实色正文和日夜配色。浮动窗口沿用 Files 的绿灯布局菜单和拖拽吸附预览，可落到半屏或四角。见 [Foot 的 Tahoe 外观](04-macos-theme.md#foot-glass)。
- macOS Tahoe 主题下，Nautilus 的侧栏透出后方已经虚化的色彩，文件区保留清晰的文字和图标。见[文件管理器磨砂玻璃](04-macos-theme.md#文件管理器磨砂玻璃)。
- Nautilus 是 Finder 外观，空格键快速预览（[04](04-macos-theme.md)）；右键菜单有「复制路径」「在终端打开」「解压到此处」（[08](08-nautilus-actions.md)）
- 启用简体中文后，Nautilus 的菜单、日期和常用侧栏书签会显示中文。见[文件管理器简体中文界面](08-nautilus-actions.md#简体中文界面)。
- 在 Nautilus 右键单张图片，选择「设置为背景…」，即可预览并应用到 Omarchy 桌面。见[右键设置桌面背景](08-nautilus-actions.md#右键设置桌面背景)。
- 终端用 zsh + Oh My Zsh：历史建议、语法高亮、增强补全（[06](06-terminal.md)）

## Obsidian 笔记

- Obsidian 换成 macOS 27 风格：菜单、命令面板、弹窗是玻璃，侧栏是浮动的圆角玻璃面板；文件夹是 Finder 蓝色文件夹，不同后缀有各自的图标；代码块是带红黄绿三个点的终端窗口。光标会平滑滑动，新输入的字淡入，拼音上屏也一样。见 [15 · Obsidian](15-obsidian.md)。
- Obsidian 的窗口按钮和 Sublime 等应用的标题栏一样在左上角：红色关闭，中间是灰色（没有最小化），绿色切换全宽，和 `Super+Alt+F` 相同，再点一次恢复。见 [15 · Obsidian](15-obsidian.md#效果)。
- 点 Dock 上的 Obsidian 图标会直接切到已经打开的窗口，图标下有运行圆点，不会再一直跳。见 [15 · Obsidian](15-obsidian.md#实现)。
