# 12 · UI 交互优化总览

简体中文 | [English](en/12-ui-interactions.md)

这些天对 Omarchy + MacShell 桌面做的界面与交互优化，按“在哪里能感觉到”分组。每条只写效果，细节、原理和回滚方式看后面链接的文档。

整体原则：**看起来和用起来都像 macOS**（玻璃材质、单色图标、深浅色同步、macOS 的快捷键习惯），**不卡**（按需捕获、事件驱动、预热），**不打架**（同一个键、同一个功能只有一个入口）。

## 深色 / 浅色：全桌面一起切换

切换的信号是 `org.gnome.desktop.interface color-scheme`。MacShell 的「外观」（含“自动”，白天浅色、晚上深色）和 `omarchy theme set macos-tahoe-light/dark` 都会写它，下面这些会跟着一起变：

| 跟着变的部分 | 文档 |
| --- | --- |
| MacShell 菜单栏、Dock、Spotlight、控制中心 | [02](02-macshell.md) |
| GTK / libadwaita 应用（Finder 风格的 Nautilus）、光标、MacTahoe 图标 | [04](04-macos-theme.md) |
| Omarchy 自带菜单（Super+Esc、Super+Ctrl+M、剪贴板、表情） | [11](11-menu-glass.md) |
| WowType 候选框皮肤（含微信内的候选条） | [09](09-wowtype-glass.md) |
| Super+K 快捷键面板 | [10](10-shortcuts.md) |
| Obsidian 笔记（主题「跟随系统」） | [15](15-obsidian.md) |

控制中心「显示」页里新加了「外观」开关，可以直接在那里切换。

Dock 的玻璃底色原来写死为深色，切换后只有右键菜单和悬停标签跟着变；现在整块 Dock 玻璃（着色、边缘高光、启动预览条）也随深浅色一起切换，见 [02](02-macshell.md)。

Dock 应用的右键菜单与 Dock 共用液态玻璃，使用同一组折射、模糊和边缘高光参数。[02 · Dock 右键菜单的液态玻璃](02-macshell.md#dock-右键菜单的液态玻璃)

## 菜单栏

- 快速连点左上角系统菜单时，文字和玻璃随开合动画一起反向。[02 · 快速连点系统菜单](02-macshell.md#快速连点系统菜单)
- 左上角系统菜单中的「重新启动」「关机」和「退出登录」单击即执行。[02 · 系统菜单](02-macshell.md#快速连点系统菜单)
- MacShell 失去响应时，启动脚本检测到连续三次探测失败后会自动重启它。[02 · Dock 和菜单栏同时卡住](02-macshell.md#dock-和菜单栏同时卡住)
- 顶栏随前台窗口切换，浏览器显示历史记录和书签，Nautilus 显示「前往」。[02 · 按应用切换顶栏菜单](02-macshell.md#按应用切换顶栏菜单)
- 顶栏工作区中，后台有窗口的工作区会在数字下方显示 3 px 小圆点并提亮数字；当前工作区只用胶囊表示，不再叠加圆点。数字右侧的布局图标和数字一样清楚，不再偏淡。[02 · 顶栏工作区占用指示](02-macshell.md#顶栏工作区占用指示)
- 「关于本机」使用和 Omarchy 系统菜单一样的磨砂底色，窗口外缘没有高亮描边。[02 · 关于本机的外缘](02-macshell.md#关于本机的外缘)
- 四指横滑切换工作区时，「关于本机」的磨砂会随窗口移动。[02 · 触控板切换工作区时的磨砂残影](02-macshell.md#触控板切换工作区时的磨砂残影)
- 全部简体中文；“关于本机”更紧凑（[02](02-macshell.md)），Edge 渠道显示为 `Edge · 提交`，后跟淡色的 `月-日 构建`，不再像降级（[02](02-macshell.md#关于本机里-edge-版本像降级)）
- 网速、CPU 温度、电池三个监控按钮，顶栏网速上传在上、下载在下，点开是玻璃面板：网速有应用流量排行和 IP（点击复制），温度有进程排行和硬件概览，电池有整机功耗曲线（仅电池供电时可测）和健康度，还能设置充电上限（[02 · 顶栏系统监控](02-macshell.md#顶栏系统监控)）
- 电池是 macOS 26 的窄胶囊，里面只有数字、没有 `%`，平时与顶栏文字同色，只有充电（绿）、电量不高于 35%（琥珀橙）和低于 20%（红）时带颜色；温度计到 65 °C 才变色，网速改成单行、单色，只显示较忙的方向（面板里仍有上传和下载）；温度计加粗，电池外框减淡、数字加大；网速、温度、电池与相邻图标间距统一；左键看电池详情并可在面板里直接切换电源模式，右键也能切换（省电 / 平衡 / 高性能），右键面板里还有「显示电量百分比」开关（[02 · 电池图标](02-macshell.md#电池图标)）
- 托盘图标统一成单色线条：Chrome、ChatGPT、Clippy、Netcatty、Remmina、Clash Verge、微信。菜单标题、工作区数字和托盘图标按各自下方的壁纸亮度单独选色，左右分色壁纸上分界两侧各用合适的颜色，不再出现灰色蒙层；只有分界穿过某个图标时，它后面才出现一块悬停大小的圆角底板。设置里的墙纸网格按整行停靠，名称去掉下划线和分辨率，收藏按钮在黑白缩略图上都清晰（[02 · Dock 图标与设置窗口](02-macshell.md#dock-图标与设置窗口)）。[02 · 顶栏随壁纸调整对比度](02-macshell.md#顶栏随壁纸调整对比度)
- 通知面板的「全部清除」居中放在通知列表下方、小组件上方。通知按应用堆叠（不显示右下角下拉箭头，点击堆叠卡片默认先展开，只显示最近 3 个应用），单击单条或已展开的通知正文有轻微按压反馈，随后跳转到应用并移除该条。单条关闭和「全部清除」时，屏幕内的卡片都会轻轻漂移并羽化消失。面板每次打开回到顶部，通知和小组件在同一个滚动区里，边缘保留玻璃模糊并逐渐淡出；小组件有：天气、股市、屏幕使用时间、电池、日历、系统、AI 用量（Claude、Codex、Antigravity 的 Gemini 额度，小尺寸同时显示 `5h` 和 `周` 双额度进度条），卡片和控制中心同样是液态玻璃，各有小 / 中 / 大三种尺寸，强调色跟随壁纸，天气卡也是半透明玻璃；右键小组件可切换尺寸、设置天气城市、增删并拖动排序全球股票代码（也可输入名称）；点「编辑小组件」后点一下换尺寸、拖动排序、「−」删除，从下方添加新组件（[02 · 通知中心小组件](02-macshell.md#通知中心小组件)）
- 通知中心打开时，已有横幅收起，新通知直接进入列表；通知卡片（含横幅与通知中心）左侧应用图标在卡片内垂直居中。点击微信卡片会恢复并聚焦主窗口，包括微信缩到托盘时。[02 · 微信通知跳转与横幅](02-macshell.md#微信通知跳转与横幅)
- 通知横幅滑入时文字和图标保持清晰，连发或撤回通知时卡片平滑补位。[02 · 通知横幅入场清晰度](02-macshell.md#通知横幅入场清晰度)
- 通知中心滚轮每格移动 160 个逻辑像素，触控板滑得更快，触屏拖动更跟手并保留惯性。[02 · 通知中心滚动速度](02-macshell.md#通知中心滚动速度)
- 自动对比度改成事件驱动：只有窗口出现、关闭、移动时才重新测亮度，背后只有壁纸时直接读壁纸文件，不再截屏，打开控制中心的停顿从约 76 ms 降到约 19 ms（[02](02-macshell.md#打开菜单和控制中心时卡顿)）
- 浮动窗口（含带 `hyprbars` 标题栏的终端与应用，在拖动、多屏重排或切回浮动时）不会越过菜单栏（[03](03-silky-gestures.md#浮动窗口不能越过菜单栏)）

## 控制中心

- 控制中心默认采用 macOS 26/27 风格的独立悬浮液态玻璃气泡（全圆角胶囊、正圆开关、清透折射与 360° 镜面高光环），深浅外观跟随系统切换，仍可在设置中随时切回统一的毛玻璃大底板（[02 · 控制中心](02-macshell.md#控制中心)）
- 新增「显示」页：亮度滑条、夜览开关、深浅色外观开关，交互方式和「声音」页一致（[02 · 控制中心](02-macshell.md#控制中心)）
- 拖动音量滑条（控制中心、菜单栏音量弹窗、菜单栏滚轮）时会发出提示音，声音大小跟着滑条走；松手时再响一次，就是最终音量。系统设置里关掉「界面音效」即可静音
- 「声音」页的输入滑条下面有实时麦克风电平条：安静时只亮几格，说话时跳起来，红色表示快要削波；只在这一页打开且麦克风未静音时监听

## Dock 与应用程序面板

- Dock 废纸篓右键菜单中的「清倒废纸篓」单击即执行。[02 · 单击清倒废纸篓](02-macshell.md#单击清倒废纸篓)

- WPS 组件在 Dock 中共用红色 WPS Office 图标，选中文字时的迷你工具栏不会增加图标。WPS 正文可以用 `Super+I` 切到 WowType。[09 · WPS 的候选栏、迷你工具栏与字体](09-wowtype-glass.md#wps-的候选栏迷你工具栏与字体)

- 系统切换到 Folio 后，Dock 上旧的 Nautilus 固定项会在更新时迁移到 Folio。[02 · Dock 中文件打不开](02-macshell.md#dock-中文件打不开)

- 「系统设置」在 Dock 显示 MacTahoe 齿轮图标。左侧导航使用压暗后的磨砂底色（深色 80% / 浅色 82%），在亮背景上保持清晰不发灰，右侧正文保持实色。[02 · Dock 图标与设置窗口](02-macshell.md#dock-图标与设置窗口)
- 菜单栏、控制中心、通知中心、应用程序面板和 Dock 改用 Hyprland 模糊：拖动窗口时玻璃同帧跟随，深浅色外观都有接近 Liquid Glass 的浅色调和顶部光泽，菜单栏背后几乎完全透明；「关于本机」的「更多信息…」按钮变淡（[02](02-macshell.md#改用-hyprland-模糊普通模糊)）
- （可选）Dock、菜单栏所有弹出面板（左上角菜单、应用菜单、Wi-Fi、蓝牙、音量、电池/状态、控制中心独立气泡、通知中心与通知横幅）及其他 MacShell 浮层（Spotlight、应用面板、窗口切换器、壁纸选择、OSD）均由 Hyprland 插件同帧画成 macOS 26/27 光学液态玻璃（边缘凸透镜折射、细微色散与 360° 双对角镜面高光）；顶部菜单栏细条（`macbarbg`）保持原生模糊（[02](02-macshell.md#dock-液态玻璃插件原型)）
- 菜单、Wi‑Fi 和通知面板沿用控制中心的清透玻璃和细亮边，通知和小组件以淡着色的独立玻璃卡片悬浮，滚动内容在 Dock 上方渐隐。[02 · 菜单和面板沿用控制中心的玻璃](02-macshell.md#菜单和面板沿用控制中心的玻璃)
- 无线局域网菜单和设置页会等待扫描完成，超时可重试，连接失败有提示。[02 · 无线局域网扫描与断线恢复](02-macshell.md#无线局域网扫描与断线恢复)
- 只保留 MacShell 的 Dock，Omarchy 自带的 Dock 永久关闭（[02](02-macshell.md#只保留-macshell-的-dock)）
- 图标的光学缩放以中心为基准，悬停放大时不再往一边偏（[02 · Dock](02-macshell.md#dock-图标与设置窗口)）
- 点过 Dock 图标后，名称标签要等指针再移动 4 px 才出现（和 macOS 一样），连续点击不再卡 60–70 ms（[02](02-macshell.md#应用程序面板交互)）
- 应用程序面板（Launchpad）：采用临界阻尼（`ζ = 1.0`）单调无回弹曲线与 `1.06× → 1.00×` 现代克制缩放，开合对称、快速连点直接连续反向；面板打开时 Dock 保持可直接点击（点「应用程序」收起、点其他图标直接切换应用，点其余桌面空白关闭）；面板内图标快速轻点即响应，触控板双指滚动松手 0 ms 切入惯性滑行，离屏图标分批渐进预热不卡帧（[02](02-macshell.md#应用程序面板交互)）
- 四、五指捏合支持 350 ms 错峰落指、底部软按钮区/侧贴大拇指豁免、对向跨度几何识别及 `3 → 4 → 5` 指动态升级（不再误变三指下滑），捏合后立即轻点不锁死，静止指针轻点外部即可关闭面板（[03](03-silky-gestures.md#触控板四指--五指捏合识别)）。
- 在 Dock 右键点「文件」，可以直接打开主文件夹、桌面、文档、下载和图片。[02 · 文件右键菜单的常用目录](02-macshell.md#文件右键菜单的常用目录)
- Folio 点黄灯后以 GPU 驱动的收拢动画缩成 Dock 分隔线和废纸篓之间的窗口缩略图，窗口就地交接给动画后再连续收拢，全程保持原亮度。点缩略图恢复。Dock 线性腾出和收回缩略图的位置（[02](02-macshell.md#窗口最小化)）
- 「罗技鼠标」（Omalogi）出现在应用程序面板和 Spotlight，图标是和 MacTahoe 统一的亮蓝瓦片；运行时 Dock 显示它自己的图标（[14](14-omalogi.md#应用程序入口与图标)）

## 玻璃与流畅度

- Vulkan 实时玻璃；菜单和控制中心只在可见时、只对和玻璃相交的窗口做捕获，窗口静止后自动降频（[02](02-macshell.md#默认玻璃参数)）
- 切换窗口焦点（浮动窗口叠放顺序变化）时，玻璃背景会跟着刷新；窗口标题变化不会唤醒刷新（[02 · 玻璃](02-macshell.md#焦点切换时玻璃背景跟着刷新)）
- 弹出面板边缘的错位暗带修复（折射强度和斜面收窄）（[02](02-macshell.md#玻璃面板边缘错位)）
- 消除鼠标指针周期性卡顿；90 Hz 内屏（[02](02-macshell.md#鼠标指针周期性卡顿)）
- 浮动窗口使用预先模糊的桌面背景后，拖过叠放的窗口仍能跟上 90 Hz 内屏（[02](02-macshell.md#90-hz-下拖动窗口卡顿)）
- 只有前台的 Folio 保留侧栏磨砂，失焦的 Folio 侧栏变成实色，同时开很多 Folio 时拖动其他窗口不再被逐个重算模糊拖慢（[04](04-macos-theme.md#folio-的-finder-外观)）
- 崩溃后不会出现两个菜单栏 / 两个 Dock；重启后菜单栏、Dock 和滚轮方向不再丢失（[02](02-macshell.md)）
- 后台程序把 CPU 跑满时，窗口动画、菜单栏、Dock 和指针仍然顺滑：Hyprland、MacShell 和输入法优先调度，接电时 GPU 不会从最低频起步（[16](16-desktop-priority.md)）

## 窗口

- Tahoe 主题和 MacShell 时钟及安装器移除了装饰外描边。[04 · 窗口外缘](04-macos-theme.md#窗口外缘)
- 计算器、Omacut、Write 和媒体查看器使用共用红黄绿按钮，半屏与四角布局按窗口尺寸启用。微信和 PuTTY 控制台的工作内容以完整不透明度显示。[系统应用按窗口标准整改](04-macos-theme.md#system-app-audit)
- Silk 自绘的浮动窗口标题栏带圆形红绿灯和半透明底色（[04](04-macos-theme.md#红绿灯标题栏)）
- MacShell 自己的窗口（设置、关于本机）保持原尺寸、居中，打开时没有白边闪烁（[02](02-macshell.md)）
- 新窗口直接显示，Firefox 等 GTK3 CSD 窗口打开首帧不再闪出虚化光晕和偏移；应用「关于」弹窗（如「关于 Obsidian」）去掉外缘模糊并贴合 18 px 圆角。见 [打开窗口时壁纸闪现](02-macshell.md#打开窗口时壁纸闪现)。
- 设置窗口左侧导航列表：鼠标滚轮每格 140 px 平滑滚动，触控板保持原生惯性（[02 · 设置窗口](02-macshell.md#dock-图标与设置窗口)）
- `Super+Shift+L`（或点击顶栏工作区数字旁的布局图标）可在进程内即时切换当前工作区的浮动／平铺／滚动布局，并在当前屏幕中央弹出液态玻璃 OSD（不进通知中心）；非浮动工作区会在顶栏图标高亮提示，右键图标可直选布局或一键全部恢复浮动。（[10 · 工作区布局切换](10-shortcuts.md#工作区布局切换居中液态玻璃-osd顶栏图标与进程内直切)）
- 窗口跨工作区拖放后会自动浮动、平铺或加入滚动布局，取决于落点工作区。[10 · 窗口移入后跟随目标工作区布局](10-shortcuts.md#窗口移入后跟随目标工作区布局)
- `Super+T` 在同一工作区平铺分屏。用 `Super+Alt+T` 进入单窗口平铺，再按一次切回浮动并恢复挪走的窗口。([10 · Super+T](10-shortcuts.md#supert))
- 通过快捷键切回浮动时，窗口上沿会避开菜单栏。([10 · Super+T](10-shortcuts.md#supert))
- 微信里点开图片或视频，查看窗口总是浮动居中，并以 900×620 的适中尺寸打开，不再顶着菜单栏；聊天记录窗口同样收窄居中（高度不低于微信自身的 720 下限）。([10](10-shortcuts.md#微信图片查看器与聊天记录窗口的默认尺寸))
- 微信在后台收到消息或更新状态时，不再自动抢焦点浮到当前窗口上方。([10](10-shortcuts.md#微信后台不再自动抢焦点置顶))
- 微信主窗口关闭到托盘再点开时保留关闭前的窗口模式/最大化状态与浮动位置尺寸，不再默认自动最大化。([10](10-shortcuts.md#微信主窗口关闭后重开保留上次状态))
- 罗技鼠标配置（Omalogi）是普通窗口：居中浮动 1280×700（不挡 Dock），可平铺 / 全屏、进 Alt+Tab，切工作区不再压在最上面；再次打开只聚焦已有窗口；有线和无线鼠标同时连着时可在窗口右上角切换（[14 · 独立窗口](14-omalogi.md#独立窗口)）
- Remmina 远程桌面显示简体中文，主窗口的实色连接列表和磨砂标题栏实时跟随日间 / 夜间。连接窗口的工具栏移到顶部，带红绿灯和连接名，按住标题栏空白处即可拖动窗口，换成细线图标和直白的提示，少用的操作收进 `⋯`，只有一个会话时隐藏标签栏。主窗口列表的选中行为强调色圆角胶囊。远程 Windows 画面在高分屏上 1:1 清晰显示，默认 150% 缩放，不再像 200% 那样又大又虚（[高分屏缩放](04-macos-theme.md#remmina-hidpi)）。见 [Remmina 简体中文与 macOS 外观](04-macos-theme.md#remmina)。
- 罗技鼠标配置的编辑区使用实色底，浮动时显示共用红黄绿按钮。见 [Omalogi 独立窗口](14-omalogi.md#独立窗口)。
- 拔掉外接显示器后，原外接屏上的工作区（如 6–9）与浮动窗口会自动回到内屏可见工作区，不再停留在缺失显示器或离屏坐标上。([10 · 外接屏拔屏回屏](10-shortcuts.md#拔掉外接显示器后工作区与窗口自动回到内屏))

## 手势（触控板 / 触控屏）

- 微信通过版本无关的原生 Wayland 适配稳定运行：顶部栏可直接鼠标拖动，触屏单指在消息列表和会话内容区均可连续滚动，右上角自带缩小按钮可最小化到 Dock、放大按钮可切换最大化与还原（[01](01-touchpad-gestures.md#微信会话列表触屏滚动)）

- 触控板：自然滚动（鼠标也是）、三指拖移、四指横滑切换工作区，过渡动画更顺（[01](01-touchpad-gestures.md)）
- 触控屏：三指滑动和边缘单指滑动切换工作区、到头回弹；触控拖动和双指缩放浮动窗口；拖动终端标题栏（[03](03-silky-gestures.md)）
- 四指 / 五指捏合识别、快速连续点击不丢（[03](03-silky-gestures.md)）
- 触控板 / 触控屏四指上滑：当前工作区所有窗口；四指下滑：当前应用所有窗口。线性跟手、松手后匀速走完，中途可再按住打断或反向；点击或轻点窗口切换过去（[13](13-window-overview.md)）
- 四指总览丢失松手事件后会自动取消手势，也可按 `Esc` 退出。[13 · 验证](13-window-overview.md#验证)
- 四指上滑总览顶部显示可点击的工作区预览，桌面壁纸全屏覆盖无底边残影。点击预览会让窗口左右滑动，触控板四指左右滑时窗口会跟随手指；总览中可直接把窗口卡片拖到顶部其他工作区缩略图静默移动，点击 Dock、菜单栏图标或顶部预览条两侧空白均可退出总览（[13](13-window-overview.md#工作区预览与切换)）

## 输入法

- WowType 候选框：圆角毛玻璃皮肤，Inter 12 号字，高亮贴边且和外框共用 8 px 圆角，半透明底色能透出模糊，选中第一个候选时两个圆角重合；修复微信里候选条重影；微信里拼音改在候选条第一行显示，连续打字时候选条不再闪烁（[09](09-wowtype-glass.md#微信里候选条连续打字时闪烁)）

## 文件管理器与终端

- Folio 使用 Finder 图标、蓝色文件夹和紧凑的红黄绿顶栏，重启和系统 Folio 更新后继续使用已安装的优化版。磨砂只出现在左侧导航栏，右侧文件区和路径栏为实色。绿灯与 `Super+F` 一样切换全屏，进入显示加号，退出显示斜角。右键或长按绿灯可选半屏和四角布局，全屏时黄灯置灰。拖窗口到左右边缘可预览并吸附到半屏或四分之一屏。分栏视图选中并展开子文件夹时，顶部路径栏、路径编辑和复制按钮同步显示到该子文件夹。顶部面包屑有独立底色，当前目录用半粗体标出，点上级可跳转，点当前目录或按 `Ctrl+L` 可编辑，点文件区空白可取消。拖动面包屑旁的空白可移动窗口，右侧复制按钮可复制完整路径。触屏单指滑动可滚动文件区。分栏视图单指轻点按左键处理，长按或双指轻点打开右键菜单。右键侧栏的「回收站」会显示居中的「清空」。见 [04 · Folio 的 Finder 外观](04-macos-theme.md#folio-的-finder-外观)。

- Folio 浮动窗口打开时首帧直接呈现，不再先闪出一整块空白虚化玻璃，在高对比背景上的侧栏圆角使用干净的磨砂边缘。侧边栏「设备」会列出未挂载的本地数据分区（如 Windows NTFS 盘，即使从浏览器等应用的「在文件夹中显示」拉起也不会丢失）并支持点击自动挂载，末尾提供单行「网络」入口，点击后才按需扫描局域网 SMB/SFTP/WebDAV/NFS 设备并在右侧显示，点开 SMB 主机可浏览共享列表并挂载进入，登录弹窗支持勾选「记住密码」自动保存到系统钥匙环。系统文件选择器在分栏视图中选中并展开子文件夹（含空文件夹）后点击「选择」或「保存」会直接作用于该子文件夹，不再少一层路径。右键解压 Windows GBK 等非 UTF-8 编码的 ZIP 时会自动识别文件名编码并以 UTF-8 正常解出中文路径，不再误报「没有可解压的内容」。空格预览与分栏右侧预览窗格均支持 `.xlsx`/`.ods`/`.csv` 与 `.docx`/`.odt`/`.pptx` 的纯 C++ 极速原生预览（表格支持多工作表虚拟化网格、单元格复制与 `Shift+滚轮` 横向滚动，文档与文本预览为鼠标滚轮提供平滑加速滚动）；旧版 `.doc`/`.xls`/`.ppt` 后台转换并磁盘缓存。新建文件夹（`Ctrl+Shift+N` 或右键）与重命名（`F2` 或右键）直接在列表/分栏/图标视图中原地行内编辑并自动全选名称，无需弹窗。见 [Folio 的 Finder 外观](04-macos-theme.md#folio-的-finder-外观)。

- 分栏视图新建文件夹时在原列命名并保存，面包屑和列位置保持稳定。浏览器、微信等应用打开文件夹或显示文件时另开窗口，保留已有窗口的浏览位置。定位文件时自动滚动到选中的文件。见 [Folio 的 Finder 外观](04-macos-theme.md#folio-的-finder-外观)。
- Files 和 Foot 的红黄绿按钮圆面等大，悬停符号用相同的路径和线宽，退出全屏用内收斜角。见 [Foot 的 Tahoe 外观](04-macos-theme.md#foot-glass)。
- Foot 使用实色正文和日夜配色。浮动窗口沿用 Files 的绿灯布局菜单和拖拽吸附预览，可落到半屏或四角。见 [Foot 的 Tahoe 外观](04-macos-theme.md#foot-glass)。
- macOS Tahoe 主题下，Nautilus 的侧栏透出后方已经虚化的色彩，文件区保留清晰的文字和图标。见[文件管理器磨砂玻璃](04-macos-theme.md#文件管理器磨砂玻璃)。
- Nautilus 是 Finder 外观，空格键快速预览（[04](04-macos-theme.md)）；右键菜单有「复制路径」「在终端打开」「解压到此处」（[08](08-nautilus-actions.md)）
- 启用简体中文后，Nautilus 的菜单、日期和常用侧栏书签会显示中文。见[文件管理器简体中文界面](08-nautilus-actions.md#简体中文界面)。
- 在 Nautilus 右键单张图片，选择「设置为背景…」，即可预览并应用到 Omarchy 桌面。见[右键设置桌面背景](08-nautilus-actions.md#右键设置桌面背景)。
- 终端用 zsh + Oh My Zsh：历史建议、语法高亮、增强补全（[06](06-terminal.md)）

## Obsidian 笔记

- Obsidian 按 Files（Folio）与 Foot 的 macOS 风格改造：左右侧栏边到边采用 Hyprland 实时磨砂玻璃，主编辑区与标签栏保持完全实色；文件夹是 Finder 蓝色文件夹，不同后缀有各自图标，代码块是终端窗口样式；光标平滑滑动且新字淡入。见 [15 · Obsidian](15-obsidian.md)。
- Obsidian 左上角红黄绿三灯对齐 12 px 实色圆面基准并支持失焦变灰：红灯关闭，黄灯最小化到 Dock 并可恢复原窗口，绿灯单击切换真正全屏（左上缘浮条退出），右键或长按绿灯打开两排 8 位置布局菜单，顶栏空白支持双击最大化与边缘拖拽吸附。见 [15 · Obsidian](15-obsidian.md#效果)。
- 点 Dock 上的 Obsidian 图标会直接切到已经打开的窗口，图标下有运行圆点，不会再一直跳。见 [15 · Obsidian](15-obsidian.md#实现)。
